# S3 Automation Script with Python and Boto3

This example shows how Lambda can list objects in an S3 bucket and upload a generated file.

## IAM permissions

Example read and write permissions for one bucket:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": "arn:aws:s3:::my-app-bucket"
    },
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject"],
      "Resource": "arn:aws:s3:::my-app-bucket/*"
    }
  ]
}
```

Remove actions the function does not need.

## List objects

```python
import boto3

s3 = boto3.client("s3")

def list_objects(bucket_name, prefix=""):
    paginator = s3.get_paginator("list_objects_v2")
    results = []

    for page in paginator.paginate(Bucket=bucket_name, Prefix=prefix):
        for item in page.get("Contents", []):
            results.append({
                "key": item["Key"],
                "size": item["Size"]
            })

    return results

def lambda_handler(event, context):
    bucket = event["bucket"]
    prefix = event.get("prefix", "")
    return {"objects": list_objects(bucket, prefix)}
```

## Upload an object

```python
import boto3

s3 = boto3.client("s3")

def lambda_handler(event, context):
    bucket = event["bucket"]
    key = event["key"]
    content = event.get("content", "Generated by Lambda")

    s3.put_object(
        Bucket=bucket,
        Key=key,
        Body=content.encode("utf-8"),
        ContentType="text/plain"
    )

    return {"uploaded": key}
```

## Example event

```json
{
  "bucket": "my-app-bucket",
  "key": "reports/status.txt",
  "content": "Daily report generated"
}
```

## S3 event trigger caution

If a Lambda function is triggered by an S3 object-created event and writes a new object to the same triggering bucket/prefix, it can invoke itself repeatedly. Use a separate output bucket or a prefix excluded from the notification.

## Best practices

- Use bucket and object ARNs scoped to the required resources.
- Enable encryption and block public access on buckets.
- Validate bucket and key inputs.
- Avoid loading very large objects fully into memory.
- Use pagination for list operations.
- Do not log object contents if they may contain sensitive data.
